# Макка · Парфюмерный уголок

Сайт на GitHub Pages: https://34agaev34-dotcom.github.io/makka-perfume/

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | Весь сайт и панель администратора |
| `catalog.json` | Каталог ароматов (порядок как на сайте) |
| `reviews.json` | Отзывы |
| `images/` | Фото, загруженные через панель |
| `admin-key.json` | Ключ доступа GitHub для панели, зашифрованный паролем (появляется после первой настройки) |

## Панель администратора

Открывается ссылкой «Вход для администратора» внизу сайта или по адресу `…/makka-perfume/#admin`.

Панель сохраняет изменения прямо в этот репозиторий через GitHub. Каждое изменение — отдельный коммит. На сайте оно появляется через 1–2 минуты, когда GitHub Pages обновит страницу.

- **Ароматы:** название, ноты, семейство (как в фильтрах), цена (без неё на карточке «Узнать цену»), объём, фото, наличие, порядок.
- **Отзывы:** посетитель заполняет форму на сайте, и отзыв приходит в WhatsApp. Вы добавляете его в панели, а потом можете скрыть или удалить.
- **Пароль:** смена пароля перешифровывает ключ доступа.

### Первая настройка

1. Создайте ключ доступа на GitHub: Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
   - Repository access: **Only select repositories** → `makka-perfume`.
   - Permissions → Repository permissions → **Contents: Read and write**.
   - Срок действия на ваш выбор. Когда он закончится, выпустите новый ключ и повторите настройку (см. ниже).
2. Откройте на сайте `#admin`. Появится экран «Первая настройка»: введите телефон, пароль и вставьте ключ.

Ключ хранится в `admin-key.json` только в зашифрованном виде (PBKDF2, 600 000 итераций + AES-GCM). Расшифровать его можно только телефоном и паролем, прямо в браузере.

**Важно.** Файл с зашифрованным ключом лежит в открытом репозитории. Короткий или угадываемый пароль позволяет подобрать его перебором. Тогда у постороннего окажется ключ записи в этот репозиторий, то есть возможность менять сайт. Чем длиннее и случайнее пароль, тем это сложнее.

### Если пароль забыт или ключ истёк

Удалите файл `admin-key.json` в репозитории (на GitHub: открыть файл → Delete file). Отзовите старый ключ в настройках GitHub. Затем откройте `#admin` и пройдите первую настройку заново с новым ключом.
